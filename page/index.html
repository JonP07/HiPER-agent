HiPER

Hierarchical Reinforcement Learning with Explicit Credit Assignment for Large Language Model Agents

HiPER trains long-horizon agents by separating high-level planning from low-level execution, then assigning credit across both time scales through Hierarchical Advantage Estimation.

Built for long-horizon agents.

Flat action-level optimization makes it difficult to tell whether an agent failed because the plan was poor, the execution was poor, or credit was assigned at the wrong temporal scale.

Architecture

Plan-execute hierarchy

Agent behavior is organized into high-level plans and lower-level environment actions, matching how multi-turn tasks naturally unfold.

Algorithm

Hierarchical Advantage Estimation

HAE estimates advantages across planning and execution levels, improving feedback quality for sparse and delayed rewards.

System

veRL-agent extensions

The codebase builds on verl-agent and veRL with additions to the agent interface, rollout handling, and training objective.

Results summary.

HiPER is evaluated on long-horizon interactive environments where agents must reason, act, observe, and recover across many turns.

How HiPER works.

The training signal is structured around the same hierarchy used by the agent at inference time.

01

Plan at a higher level

The policy proposes abstract intent for a task segment instead of optimizing every action in a single flat stream.

02

Execute with environment feedback

Low-level actions interact with ALFWorld or WebShop, produce observations, and expose where a plan succeeds or fails.

03

Assign credit across levels

Hierarchical Advantage Estimation separates planning credit from execution credit so delayed outcomes can train the right behavior.

Why hierarchy matters

Long-horizon agent tasks rarely fail at a single action. HiPER gives the optimizer a better decomposition: what the agent should be trying to do, and how well it carried that intent through the environment.

This repository keeps that decomposition visible in both rollout collection and reinforcement learning updates.

Install and run.

ALFWorld and WebShop have different environment constraints. For WebShop, use a separate Python 3.10 environment.

veRL and HiPER

conda create -n verl python==3.12 -y
conda activate verl

pip3 install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
pip3 install flash-attn==2.7.4.post1 --no-build-isolation
pip3 install -e .
pip3 install vllm==0.8.5
pip3 install peft==0.17.1

ALFWorld

pip3 install gymnasium==0.29.1
pip3 install stable-baselines3==2.6.0
pip install alfworld
alfworld-download -f

WebShop environment

conda create -n verl-webshop python==3.10 -y
conda activate verl-webshop

cd ./agent_system/environments/env_package/webshop/webshop
./setup.sh -d all

Run examples

bash example_scripts/HiPER_trainer/run_alfworld.sh
bash example_scripts/HiPER_trainer/run_webshop.sh

For WebShop, install the project dependencies from the repository root after setting up the WebShop environment. The typer warnings emitted by spacy and weasel can be ignored.
